Pencadangan & Pemulihan Basis Data (JSON)

1. Unduh Cadangan Database

Simpan seluruh data sekolah, siswa, panitia, pengawas, dan distribusi ruang ke dalam 1 file JSON aman di komputer Anda.

2. Pulihkan Database dari File JSON

Unggah file JSON backup yang pernah Anda unduh untuk memulihkan seluruh lembar kerja sistem secara otomatis.

3. Reset ke Pengaturan Pabrik (Factory Reset)

Menghapus seluruh data siswa, panitia, pengawas, distribusi ruang, dan mengembalikan sistem ke setelan awal pabrik. Tindakan ini permanen dan tidak dapat dibatalkan.
